This directory should contain texture files for custom skins.

FILES:
- tynker_default.png: Your Tynker skin texture
- mojang_pink.png: Mojang skin variant with pink background and magenta coloring

HOW TO ADD MOJANG PINK SKIN:
1. Create a 64x64 PNG image with:
   - Pink background (RGB: 255, 0, 255 or similar magenta/pink tones)
   - Character design in magenta/hot pink colors
   - Standard Minecraft player texture format

2. Place mojang_pink.png in this directory
3. The game will automatically load it as a selectable skin
4. Press Tab to cycle through skins including "Mojang Pink"

TEXTURE FORMAT:
- Size: 64x64 pixels minimum
- Format: PNG with transparency support
- Character design: Standard humanoid form
- Color scheme: Pink/magenta background with complementary colors
